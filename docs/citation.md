# Citation

If climval helps your work, please cite the software. The repository holds a
[`CITATION.cff`](https://github.com/northflowlabs/climval/blob/main/CITATION.cff)
file; GitHub shows it as "Cite this repository". Each release is archived on
Zenodo with a DOI.

```bibtex
@software{climval,
  author    = {Pedersen, Tom Danny and {Northflow Technologies AS}},
  title     = {climval: validation of climate model output against reference data},
  version   = {0.2.0},
  year      = {2026},
  publisher = {Zenodo},
  url       = {https://github.com/northflowlabs/climval},
  license   = {Apache-2.0}
}
```

Please also cite the data you compare, for example ERA5 (Hersbach et al.
2020, <https://doi.org/10.1002/qj.3803>) and the CMIP6 models by `source_id`
and institution (Eyring et al. 2016,
<https://doi.org/10.5194/gmd-9-1937-2016>), and the methods you report, such
as Taylor (2001) for the Taylor diagram.
